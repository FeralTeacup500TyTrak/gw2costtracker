GW2 Cost Collector - Step 1

Upload the CostCollector folder to the ROOT of your existing GitHub Pages repository, alongside data/, Collectibles/ and CompletionCost/.
Open https://YOUR-GITHUB-PAGES-URL/CostCollector/ and click Scan project JSON files.
Export both JSON files after scanning. This version reads existing files and does not modify them.
No Python, BAT or EXE required on your PC.

The scanner deliberately does not treat support/family files as additional completion objectives. Recipe IDs are deduplicated across professions; skin IDs and item IDs remain separate namespaces.
